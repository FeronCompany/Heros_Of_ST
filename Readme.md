# Heros Of Sui&Tang (隋唐群雄)
- This is a strategy game based on the Sui and Tang dynasties of ancient China. Players can choose to play as one of the many heroes from these dynasties, each with their own unique abilities and skills. Heros Of Sui&Tang tries to offer an exciting adventure through ancient Chinese history.
- 本游戏是基于中国古代隋唐时期的一个策略游戏。玩家可以选择扮演这些朝代中的众多英雄之一，每个英雄都有自己独特的能力和技能。《隋唐群雄》力求为玩家提供一次穿越中国古代历史的激动人心的冒险。

## Building Game As Developer
- Clone the repository: `git clone <repository_url>`
- Download content packages from release
- Unzip content packages, replace the `Content` folder in the project directory with the unzipped `Content` folder, and copy the `Map` folder to the `Config` folder in the project directory
- Hold shift key, right-click `Heros_Of_ST.uproject`, select "Generate Visual Studio project files"
- Double-click `Heros_Of_ST.sln` to open the project
- Enter Visual Studio, choose `Heros_Of_ST` as the default project, and select Debug or Release mode
- 克隆代码库：`git clone <repository_url>`
- 下载发布中的内容包
- 解压内容包，用`Content`替换项目目录的 `Content` 文件夹，拷贝`Map`到项目目录的 `Config` 文件夹
- 按住shift键，右键点击`Heros_Of_ST.uproject`，选择"Generate Visual Studio project files"
- 双击`Heros_Of_ST.sln`打开项目
- 进入Visual Studio，选择Debug或Release模式，将默认项目设置为`Heros_Of_ST`，点击运行按钮开始游戏开发
